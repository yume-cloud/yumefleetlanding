# yumefleet.com — лендинг Yume Fleet

Статический сайт продукта Yume Fleet (учёт таксопарков): HTML, CSS, JavaScript, без сборки. Хостинг: GitHub Pages из ветки `main`. Все пути относительные, поэтому сайт работает и по адресу проекта на github.io, и на корне домена yumefleet.com.

## Структура
- `index.html` — главная (единственная страница на данный момент).
- `css/styles.css` — стили. Токены бренда: жёлтый `#F0B100`, текст `#0D0D0D`, фон `#FAFAFA`, шрифт Geist.
- `js/main.js` — анимации, вкладки, живая таблица долгов, форма.
- `assets/logo/` — знак «шашки» и плитка, `assets/screens/` — экраны продукта из макетов репозитория yume-fleet, `assets/fonts/` — Geist локально.

## Форма заявки
Без бэкенда форма открывает WhatsApp с заполненным текстом. Чтобы отправлять заявки в Telegram, укажите адрес серверной функции в атрибуте `data-endpoint` у `<form class="form">` (функция такая же, как в репозитории yume.cloud, `api/lead.js`).

## Домен
Settings → Pages → Custom domain: `yumefleet.com`. У регистратора: A-записи корня на 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153 и CNAME `www` → `yume-cloud.github.io`.
