# Сцена wialon — «Карточка машины: место и пробег»

Для `.phero__vis` страницы `/integrations/wialon/`. Белая карточка 520px: шапка с госномером
`015 ADM 02` (класс `plate` из общих стилей), Chevrolet Cobalt 2022, зелёная точка «Wialon»;
плитка карты с подписью «Местоположение · Алматы»; две плитки ниже — **Пробег** и **Аренда**
(Ерлан С., ставка 9 000 ₸ в сутки, сменщик Асан); серая строка «Подключается по запросу».

## Что показывает
Цикл `data-step`: `0` (сброс, 420 мс) → `map` (жёлтый след по улицам дорисовывается до точки за 1,3 с,
пин появляется на её конце, подпись «Алматы» проявляется; 1,7 с) → `odo` (пробег доезжает до
48 312 км за 1,2 с rAF с ease-out, у пина пульс; 1,5 с) → `done` (строка «по запросу» проявляется;
финал держится 3,4 с). След — CSS-переход `stroke-dashoffset` с `pathLength=100`, скачков нет.
Запуск через IntersectionObserver threshold 0.35. Высота карточки 400px на всех шагах: место под
строку финала зарезервировано, раскладка не прыгает.

Текст сцены — только то, что есть на странице: местоположение и пробег в карточке машины рядом
с арендой, «без звонка водителю», интеграция по запросу. Про историю поездок, геозоны, скорость
и «уже у всех» сцена не говорит. Единственное число не из брифа — пробег 48 312 км: без него
сюжета «пробег доезжает до числа» нет. Денег в сцене одно значение — ставка 9 000 ₸, сходиться
нечему.

## Курсор
Нет: в сцене ничего не нажимается, данные приезжают от трекера сами.

## Без движения
`prefers-reduced-motion` или ширина ≤ 900px: сразу `data-step="done"`, пробег подставляется конечный,
переходы и пульс отключены.

## Что поправил после просмотра
- Верхняя серая «улица» карты проходила прямо через подпись «Алматы» → подпись получила плашку
  `rgba(246,246,246,.92)` с радиусом 8.
Проверено 06.10 на 1100×620, Playwright + bundled Chromium 1217 headless, кадры настоящие
(`shot-1-map.png`, `shot-2-odo.png`, `shot-3-done.png`: 0 км → 43 460 км → 48 312 км). Карточка
587..1100 × 72..472, за её границы не выходит ни один элемент (проверено `getBoundingClientRect`
по всем потомкам), обреза и налезания нет. Playwright MCP был занят другой сессией, снимал скриптом.
