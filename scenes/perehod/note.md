# Сцена perehod — hero страницы /perehod/

## Что показывает
Карточка переноса «Yume Cloud → Yume Fleet»: чеклист из трёх разделов, которые отмечаются сами,
без клика. Шапка: стрелка от старого к новому, жёлтый бейдж «Yume Fleet», счётчик «0 из 3».
Полоса под шапкой заполняется по третям вместе со счётчиком.

Строки (демо-данные страницы, ничего нового не выдумано):
- Машины — плашка `015 ADM 02` (общий класс `plate plate--sm`), Chevrolet Cobalt · 2022.
- Водители — Ерлан С. · сменщик Асан.
- Аренды — 9 000 ₸ в день · выкуп 7 200 000 ₸ · взнос 1 500 000 ₸.

Внизу два тега из текста страницы: «Цена прежняя» (замок) и «Данные переносим мы» (галка).
На финале они подсвечиваются жёлтой рамкой. Дата переноса нигде не названа.

Шаги (`data-step`, старт по IntersectionObserver threshold 0.35, цикл):
1. `in` — все строки «в очереди», полоса 0, счётчик 0.
2. `cars` → `drivers` → `rents` — текущая строка жёлтая «переносим», полоса и счётчик едут через rAF
   (1,1 с на треть, без скачка), по доезде строка становится зелёной «готово», пауза 0,45 с.
3. `hold` — «3 из 3», все галки, теги жёлтые; держится 3,6 с.
4. `reset` — карточка гаснет 0,55 с, заново.

## Курсор
Нет. В сюжете нет клика: разделы отмечаются сами, это и есть обещание страницы («данные переносим мы»).

## Reduced motion и ширина до 900px
Сразу финал (`hold`, 3 из 3, все «готово»), цикл не запускается. Проверено Playwright,
viewport 800×900 + `reducedMotion: reduce`: `step: hold, count: 3, done: 3`.

## Что поправил после просмотра (Playwright chromium 1200×820, 06.10, кадры есть)
- Строка «Аренды»: сумма «1 500 000 ₸» переносилась по середине («000 ₸» и одинокий «₸» на новой
  строке). Деньги обёрнуты в неразрывные `<i>`, разделитель «·» рисуется CSS внутри неразрывного
  элемента, чтобы не висеть в конце строки.
- Строки были разной высоты (70/62/78 px) — задана `min-height: 70px`, две первые теперь ровно 70,
  третья 84 из-за второй строки сумм (намеренно, текст не обрезан).
- Обреза и налезания нет, горизонтального скролла нет (scrollWidth 1200 при окне 1200).
