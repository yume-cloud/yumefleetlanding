# Сцена debtors — «Проверка по ИИН до выдачи»

Страница: /integrations/debtors/. Атрибут `data-debtplay`, классы `debtplay*`.

## Что показывает
Карточка заявки водителя: «Заявка из WhatsApp», Ерлан С., ИИН замаскирован (90••••••••12),
справа госномер 015 ADM 02 (`class="plate plate--sm"`) и Chevrolet Cobalt · 2022.
Одна строка реестра: «Реестр должников · data.egov.kz · запрос по ИИН». Справа плашка
«Проверяем…» со спиннером, под строкой жёлтая полоса едет 0 → 72 % → пауза → 100 %
(rAF-tween, без скачка). Потом плашка становится зелёной «✓ Чисто», строка подсвечивается
жёлтым, под ней «Исполнительных производств нет · проверено 6 окт, 10:42» (дата и время
подставляются из `new Date()` — проверка идёт на заявке, то есть сегодня). Чёрный блок
«Выдача машины / Ждёт проверки» с замком становится жёлтым «Можно выдавать», дужка замка
открывается. Подпись внизу: «Результат и дата остаются в карточке водителя. Повторим перед
договором» — обе половины есть в тексте страницы (блоки «Результат в карточке» и «Перед договором»).
Три проверки со страницы /features/check/ не повторяются — реестр один.
Денег в сцене нет (ставка и выкуп к сюжету не относятся), сходиться нечему.

## Шаги и тайминги (`data-step`)
in 800 мс → check (полоса 1400 мс до 72 %, пауза 350 мс, 500 мс до 100 %) → clean 600 мс →
hold 3800 мс (финал держится дольше всех) → reset 550 мс. Цикл через IntersectionObserver
threshold 0.35. prefers-reduced-motion или ширина ≤ 900px: сразу `hold`, полоса 100 %,
переходы и спиннер выключены.

## Курсор
Нет. В сцене никто ничего не нажимает: проверка запускается системой по заявке, сюжет
двигает ответ реестра, а не клик.

## Что поправил после просмотра (looked: true, Playwright + системный Chrome 1200×800, 06.10.2026)
- Подпись строки «data.egov.kz · исполнительные производства» резалась многоточием на
  ширине карточки 440px. Заменил на «data.egov.kz · запрос по ИИН»; слова «исполнительных
  производств нет» остались в строке вердикта. После правки элементов с переполнением нет
  (замер `scrollWidth > clientWidth` по всем потомкам: пусто).
- Налезания нет: шапка (имя 119px слева, номер+модель 140px справа) не пересекаются,
  карточка 440×357px, строка реестра 394×63px, плашка результата 129×26px внутри строки.
